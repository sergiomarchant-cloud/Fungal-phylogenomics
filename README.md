Este repositorio contiene una serie de scripts para realizar estudios filogenómicos a partir de genomas sin ensamblar disponibles en GenBank y datos propios. 
Aquí se incluyen scripts para descargar los datos crudos de genbank a partir de una lista de codigos de Accesion number. Además se incluye el código para usar la plataforma MPGAP para ensamblar los genomas. Finalmente se incluye un script para aprovechar los analisis de BUSCO para hacer mineria de genes homologos entre los genomas y así realizar los análisis filogenómicos con IQTREE y ASTRAL.
